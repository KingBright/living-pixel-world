# Pixel Character Forge v0.2 设计补充

## 目标

在不增加逐角色手绘动画成本的前提下，提高五官和衣服的可读性，减少动态内部黑边，并将原来的动作播放器升级为可保存、可重用的动作编辑器。

## 像素与轮廓

身体、脸部和衣装仍来自参数化形状。内部骨骼和物理保留连续坐标，最后按选定的 128/192/256/384/512 画布重新栅格化。显示缩放与实际生成分辨率分开；增加像素不能仅靠放大图片。

细节图元依附角色局部坐标，随身体、衣装和骨骼变化。眼睑、瞳孔、鼻唇、衣领、纽扣、腰带和护甲高光增加辨识特征。脸部小窗来自同一角色在 512 画布重新生成的结果。

默认关闭每个图元的黑色边界，改为最后合成剪影的一像素材质色暗化。头发和披风绘制连续带状轮廓，避免逐物理段形成黑色横线。旧黑边模式保留作对照。

## 动作资产

AnimationClip 独立于人物 Recipe。基础动作提供整体意图，关键帧记录根、胸、头、手脚以及武器和身体旋转的偏移。位移随身高缩放，旋转以角度编辑。修改体型后再次求解 IK，双手武器保留共享握持框架。

时间轴支持五种插值、移动和删除关键帧、整体重定时、镜像和单次/循环播放。编辑事务支持撤销重做。预设不是只读展示，可以保存成新的动作 JSON 并在其他角色上加载。

物理按 120 Hz 固定步长运行。拖动播放头时从初态重放，避免同一时间点出现随机的头发和披风状态。事件标记只属于资产，不自动实施游戏伤害。

## 导出与验证

编辑器和命令行共用同一渲染与动画核心。导出当前自定义动作，而不是绕过修改重新播放原预设。高分辨率图集采用分页，schema 2 用 page 与 rect 定位每帧。

验证分为数值合同、实际编译、真实图像与界面试跑。当前结果及未验收项详见 VERIFICATION.md。继续降低美术成本依赖更好的轮廓和材质模板，而不是增加随机参数数量；完全不同拓扑仍需要新的骨架与生成规则。
